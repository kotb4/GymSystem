# دليل تشغيل ورفع الديمو المستقل (GymSystem Standalone Demo)

هذا المجلد يحتوي على كافة ملفات حزمة الديمو المعزولة تماماً عن البرنامج الأساسي للعميل:

## الملفات المضمنة:
1. `Dockerfile`: بناء خفيف يعتمد على Node 24 Alpine جاهز لأي مزود سحابي مجاني.
2. `render.yaml`: مخطط الإطلاق المباشر بضغطة زر واحدة على منصة Render.com المجانية.
3. `sandbox-manager.ts`: محرك العزل والتنظيف الذاتي للساندبوكسات.

## خطوات الرفع على Render.com (مجاناً 100%):
1. قم بإنشاء Web Service على Render واختر الـ Dockerfile الموجود في هذا المسار `demo-standalone/Dockerfile`.
2. يتم بناء السيرفر وتشغيله تلقائياً مع توفير شهادة SSL مجانية ورابط دائم للعملاء لتجربة السيستم دون مساس بالبرنامج المكتبي الأساسي.
