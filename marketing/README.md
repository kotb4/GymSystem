مرحباً بك في مجلد الهوية التجارية والتسويق الخاص بنظام **GymGate**.
تم تجهيز هذا المجلد ليكون المرجع الشامل والمتكامل لكل ما تحتاجه في:
1. بناء الحملات الإعلانية والتسويقية (الممولة والعضوية).
2. إدارة صفحات التواصل الاجتماعي (Facebook, Instagram, TikTok, LinkedIn).
3. التواصل المباشر مع أصحاب الصالات الرياضية ومديري النوادي (Sales Outreach).
4. الحفاظ على هوية بصرية ولونية موحدة واحترافية عالية.
